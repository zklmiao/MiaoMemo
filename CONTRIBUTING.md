# Contributing to MiaoMemo

Thanks for your interest in contributing!

## Getting Started

```bash
npm install
npm start
```

## Pull Request Process

1. Fork the repository and create your branch from `main`.
2. Test your changes by running `npm start`.
3. Ensure the app builds successfully with `npm run build`.
4. Update the README if your change introduces new features or alters existing behavior.

## Code Style

- Follow the existing code style and naming conventions.
- Keep functions small and focused.
- No external libraries without a good reason — MiaoMemo is intentionally dependency-light.

## Reporting Bugs

Open an issue with:
- Your Windows version
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable
